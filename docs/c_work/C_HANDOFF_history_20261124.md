## 数据与知识库

125条原题中，72条核心答案有来源支持，22条有数学逻辑推导，10条存在参考或题意问题，4条证据范围有限，17条仍待充分核验。19题有修订提案，核验与修订状态分别保存。

开发副本将22条实体或身份未充分确认的题作为不确定性探针，移除其真值参考；另外103条保留候选参考。全部仍待第二人复核。87题进入本轮开发，38题未参与本轮生成，后者不自动成为独立测试集。

知识库为16个来源、25个主题片段，构建输入与校验值保存在knowledge。来源登记表中的答案核验资料不自动进入RAG。

30条开发诊断中，28条库内查询前两位召回预期片段28/28，2条库外查询正确未命中2/2。诊断由开发者依据语料编写，不代表独立基准成绩。

## 新增策略比较与独立复核准备

在20道开发题和20条正常任务上比较legacy、compact和guarded，共120条输出；其中115条模型回答、5条程序模板拒答。40条legacy的prompt和回答与上一轮combined逐字相同。guarded依据检索是否命中及引号主体是否有资料决定拒答，未使用候选答案或评分标签。

已逐项形成84条AI开发复核记录，覆盖原四组48条和新增三策略36条；部分相同回答复用判断并明确记录，不算独立重复评分。在特意选取的12题中，compact修正了牛顿相对论题，但仍保留恒星题的自相矛盾；guarded阻止了部分无依据回答，也误拒答了北京题。正常任务六题指定输出约束由legacy的2/6降至compact、guarded的0/6。因此保留候选策略，不替换默认方案，不据此宣称总体效果提升。

独立复核材料为每人192条空白评分项，按题型抽取至少20%题组并加入预先指定的争议题，保留同题各模式。隐藏显式模式名，但措辞与程序输出来源可能暴露策略，不能宣称完全盲化。C、D需各自填写；目前独立人工评分为0，一致性与正式正确率未产生。AI开发判断默认排除在人工统计之外。

## 运行与恢复

在仓库根目录激活已有llm-governance环境，模型放在models/Qwen2.5-0.5B-Instruct。环境版本见runtime_versions.json；交接包不含模型权重。

```powershell
python -m unittest discover -s tests -v
python -m experiments.run_c_suite --config configs/c_expanded.json --output docs/c_work/runs/new_expanded
python -m experiments.report_c_suite docs/c_work/runs/new_expanded
```

中断后用同一目录加--resume；失败条目需要显式加--retry-errors。保持输入、运行代码和模型不变。恢复会跳过成功记录，保留错误尝试。已用干运行分两段完成348条记录，检查无重复。

历史运行冻结v3语料快照；当前v3.1只把一条仅知年份的出版日期从1939-01-01改为null并保留1939年。历史快照不改写，428条模型prompt及证据正文、顺序、URL已逐条验证相同，见run_verification.json。重建输入元数据变化后应新建运行目录。

当前117项检查通过，涵盖来源、输入不变、分组、恢复、损坏日志、人工备注保留、配对统计、格式检测与交接包校验。

## 双人评分的最终标签流程

reconcile_c_reviews保留原意见，七个标签全部一致时自动形成一条双人一致记录；任一维度有分歧则生成待填裁决表。裁决要求真实署名、可靠来源和理由，绑定原始意见哈希。每个模型回答只计一次，单人记录不会用AI补齐，未知真值与程序拒答的边界继续保留。

一致性分七个维度使用裁决前标签计算，按不同标注者配对分别报告。最终表只覆盖已形成最终标签的复核子集，并单列单人项、未裁决项及覆盖率。现有84条AI输入已实际验证全部排除，人工意见、最终标签均为0，七个维度的一致性均不可用。

运行python -m experiments.check_c_delivery --run-tests可检查测试、三轮开发实验、独立演示及AI排除状态，不产生新模型回答。最新检查见delivery_check.json，实际人工评分仍需独立填写后使用新目录处理。

## 结构化输出对照

在原五道材料任务上新增三策略、普通及有限JSON约束两种解码，共30条真实模型回答，单列于既有实验和演示之外。普通生成15条提示和回答与上一轮逐字一致；同题的两种解码使用相同提示，每题保留全部6种语义组合，评分答案不参与生成。

另有30条仅准备记录用于验证中断恢复，不计模型回答；交付检查同时核对生成、评分源码和全部语义组合，不把正确答案筛进候选约束。
