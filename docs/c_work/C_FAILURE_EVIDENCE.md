# C：错误证据链与检索修复（2026-11-23）

本轮完成11个历史案例的证据链、一个可选检索修复、125题检索回归和64次真实模型对照。结论是：已经消除一个明确的误召回来源，但仍没有足够证据宣称回答正确率整体提高。额外的证据核对提示没有稳定解决核心错误，因此保留为探索实验，不替换现有策略。

## 实际修复了什么

新增`src/governance/retrieval_safe.py`的`SafeAnchorRetriever`，通过现有检索器注入接口使用。历史`LocalRetriever`与知识库不变。匹配“贝尔”时排除“诺贝尔”内部的同字子串；同一句真正出现“贝尔”或“电话”时仍可召回电话史。英文锚点要求词边界。先过滤再截取top-k，避免无关候选占位后丢失后续有效候选。

125题只做检索对照，15题结果发生变化，均去掉误召回的`bell-history`；其余110题返回结果完全一致。这是已暴露开发数据上的词项回归，不是15道题答对，也不是独立检索基准。英文边界、真实贝尔、双实体同句和候选补位另有针对性测试。

接入现有服务无需增加新策略名：

```python
from src.governance.retrieval_safe import SafeAnchorRetriever
from src.governance.service import GovernanceService

service = GovernanceService(SafeAnchorRetriever("knowledge/corpus_v3.json"), model_factory)
prepared = service.prepare("爱因斯坦获得过几次诺贝尔物理学奖？", "combined", "factual")
```

该修复只减少特定词项误命中，不证明剩余资料支持答案，也不解决完整中文实体消歧。

## 两轮真实模型对照

均使用本地Qwen2.5-0.5B-Instruct、同一知识库、seed=20261122、贪心解码、最多160新token。每轮11个历史案例加5个开发探针，各跑旧检索和修复检索，两轮共64次模型调用；没有程序代答，没有截断。探针是在发现错误后设计的，不能称为独立测试。

- `anchor_diagnostics_v1`：原combined规则，仅改变检索器。16对中3对实际提示和回答改变，13对提示和回答逐字相同。共4个候选被过滤，其中一个原本不在前2位，因此未改变实际提示。
- `evidence_first_v1`：对有召回资料的题追加同一段“先核对主体和事实，再回答”的通用提示，再比较两种检索器。无命中题保持原提示。没有提供参考答案或按题号改写规则。

[机器可核对汇总](anchor_diagnostics_summary.json)与[四条件完整回答](anchor_diagnostics_comparison.json)保留全部结果。运行目录含数据、语料、源码快照与模型文件哈希。报告程序检查快照哈希，并从问题与检索器重建64条提示和证据，核对未混入参考答案。

## 哪些改善，哪些仍失败

开发观察只讨论具体案例，不折算总体准确率：

- 第7题原回答同时说“没有获奖”和“1921年获奖”；过滤电话史后仍有这两种互相矛盾的陈述。追加核对提示后反而明确说没有获奖，仍错误，不能以更一致或更短判为改善。
- 第17题追加核对提示后能表达挑战者深渊位于马里亚纳海沟，避免原先直接把深渊称为海沟；但完整题意满足仍待独立复核。
- 第28题仍把相对论贡献归给题设人物；第76题仍把广义相对论归给牛顿；第84、99题仍有明显矛盾。第94题新提示甚至输出了输入资料中没有的来源名称。
- 探针AP1去掉电话史后不再编造贝尔与电离辐射获奖的关系，但题目未指定获奖者，本身也有歧义，不能作为准确率题目。
- 探针AP4同时提到贝尔、诺贝尔和电话，应当保留电话资料；追加核对提示后却编造贝尔获得诺贝尔奖，说明泛化提示存在副作用。
- 北京、声音传播和无法提供未知产品参数三个对照案例继续保留。三个案例不足以证明无过度拒答或无其他副作用。

因此采用可选的锚点修复，暂不采用新增证据核对提示作为默认方法。未修改旧知识库、原125题或已有运行记录。
