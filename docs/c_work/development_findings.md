# C 开发实验观察

观察基于smoke_v1和smoke_v2的逐条回答，用来定位下一阶段问题。以下是开发者的案例检查，尚未经过D独立评分，不能据此计算正式正确率、幻觉率或方法提升幅度。

## 数据修订

第111题原答案为12，但原问题问144的平方根。实数解有12和-12。四组模型回答都只提到12或√144=12，因此使用旧参考答案做简单匹配会掩盖题意与完整性问题。修订建议已保留在data_audit.json。

## 回答约束减少额外陈述的案例

第3题原始回答答中了太平洋，但附加了不一致的面积与单位换算；约束组只回答太平洋。第10题原始回答答中月球后继续添加多项事实；约束组简短回答地球唯一的天然卫星是月球。这些案例提示需要分别评价核心答案与附加事实，不能只做答案包含匹配。

## 检索命中仍不遵循资料

smoke_v2第19题retrieval组检索到planets-02，其中明确木星距离太阳第五近，模型回答却写“第四位，与土星并列”。combined组在该题只回答木星。这是正确资料未被模型忠实使用的故障，不应归为没有检索到相关资料。

第99题combined组先说太阳是太阳系唯一一颗恒星，接着又说太阳系还有其他恒星，回答内部自相矛盾。即使命中sun-01，生成约束仍未可靠执行。

## 无资料时仍继续生成

第28题询问一个待核验人物的相对论贡献。v1因“贡献”等通用词召回无关太阳、电灯片段。v2增加从资料主题提取的匹配词后不再召回这些片段，但retrieval和combined组仍生成未经支持的履历和理论。修复召回问题不等于解决无证据生成。

该人物题原参考中“不存在”的断言仍待核验；本观察仅指出模型陈述缺少当前证据支持，不以知识库未命中证明人物不存在。v1和v2均保留，不能删掉更差的开发输出。

## 只给来源而未回答

第94题combined组输出美国能源部链接，没有回答题设中的人物归因。链接真实不等于完成任务，也不等于引用确实支持回答。后续评分应同时区分相关性、证据支持与回答有效性。

## 下一步实验

在开发集比较更短的回答约束、显式先检查题设和无证据时的不确定性表达。优先增加知识库主题覆盖，保留检索失败与生成失败的分类。任何新增规则都应记录版本，正式测试前冻结，不根据正式测试结果选择提示词。当前不增加规则硬编码的答案或把参考答案写入检索库。
