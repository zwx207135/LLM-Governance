# 联合入口批量工具与一致性v2

这一批完成可配置批量入口、逐条落盘与恢复、材料进入实际提示的边界修复、一致性检查v2，以及24案例四条件的实机对照。完整记录见[96条报告](runs/joint_batch_v1/report.md)，配置见[批量配置](../../configs/c_joint_batch.json)，检查见[delivery_check.json](delivery_check.json)。

## 完成的工程能力

- 输入、语料、配置、运行源码和模型文件均记录校验值；每次新实验使用新目录，恢复验证原合同及快照。
- 每条记录同步落盘；成功项跳过，错误项只有显式retry-errors才重试，保留旧尝试。
- 四条件按问题轮换执行次序，固定greedy及种子，模型预热单列；请求时延包含准备与审计，不能直接当作纯生成时延。
- 给定材料会同时进入effective_question、实际模型提示和审计上下文，日志另保留原始问题，不再依赖调用方自行复制材料。
- config批量入口拒绝reference、gold等未定义输入字段，不接受任意Python模块名作为配置，避免无意把参考答案或未经审阅的代码接到生成边界。
- 保留模型回答与程序拒答的不同来源、调用数、阶段轨迹与异常。原始answer不自动改写。

## 一致性v2

在原编号、URL、结构与依据状态检查上，新增材料ID及文本校验、非法结论值、非JSON数值常量，以及显式quote字段是否为所选材料的精确子串。材料只接受不重复的M编号和文本。

quote精确匹配不是语义支持证明：原文存在这句话，仍可能主体不同、脱离上下文或不能推出结论；空白差异也可能导致精确匹配失败。返回semantic_support仍为not_evaluated，factual_accuracy仍为空。未知URL、不确定性伴随数字属于筛查，不能强行计作事实错误。旧v1历史筛查和原回答均保留。

## 24案例、96条实机结果

包含12条属性配对输入、4条事实/数学问题、2条未核实实体问题、4条严格输出任务和2条材料任务。属性配对覆盖性别、年龄、地域，部分为正反顺序重复，不是12条独立偏见测试。四条件使用相同案例，仍是开发集成检查，不是E3联合治理效果验证。

| 条件 | 模型生成 | 程序拒答 | 触发审计 | 四项严格任务符合 |
| --- | ---: | ---: | ---: | ---: |
| combined，偏见提示关闭 | 24 | 0 | 1 | 3/4 |
| combined，偏见提示开启 | 24 | 0 | 1 | 3/4 |
| compact，偏见提示开启 | 24 | 0 | 1 | 2/4 |
| guarded，偏见提示开启 | 10 | 14 | 1 | 2/4 |

全部96条成功，其中82条模型生成、14条程序拒答。guarded六个属性配对的回答逐字相同，来自固定拒答，不能因此认定公平性改善；更快的请求也受跳过生成影响。四条件均有材料依据字段不符合，全部原件及信号保留。未触发信号不等于判断正确。

实际完成两项恢复验证：仅准备运行在第3条后中断再恢复，最终96条唯一prepared记录且无模型回答；完整实机运行再次resume，原日志哈希不变、未加载模型也未重复生成。前者单列，不冒充96条新模型结果。

## 使用方法

```powershell
python -m experiments.run_c_joint_batch --config configs/c_joint_batch.json --output docs/c_work/runs/my_joint_batch
python -m experiments.report_c_joint_batch docs/c_work/runs/my_joint_batch
```

中断恢复时重复原命令并加--resume；失败记录需要显式加--retry-errors。--dry-run可不加载模型准备运行，--stop-after N用于检查恢复。每次改变代码、配置、模型或输入应新开目录，旧运行保留当时的源码快照。

Python接入使用src.governance.joint_batch.JointBatchService，answer参数包括question、strategy、category、bias_mode、materials。materials格式为列表，例如[{"id":"M1","text":"太阳是恒星。"}]。实例串行复用模型，外部偏见hook仍需显式版本ID且不得删除问题和证据。现有偏见治理实现尚未提供，内置提示只是原型接口中的一个显式选项。

独立人工评分仍为0，当前自动完成的是接口、恢复、材料传递、限定输出和低级一致性检查。复杂语义支持、偏见成效与完整项目验收不能用这些运行统计替代。

实机完成后另补强了重复JSON键的拒绝处理和可选group字段的缺省记录；本轮96条原件的审计结果经最新检查器重算仍一致。历史运行保留生成时源码，不回填修改。后续运行使用最新入口及新目录；恢复历史任务需保持其原代码合同。
