## 检索方法及迭代

三组最初对照保持同一combined提示和生成参数，只改变：

1. `v3_safe`：旧库加前轮锚点修复。
2. `v4_safe`：新库加同一锚点修复，隔离补库带来的变化。
3. `v4_scoped`：新库再根据片段的年度、类别、主体、统计范围筛选。

年度公告新增`scope`元数据，数学与普通问题不会因此改写答案；模型仍实际生成。次数问题可组合个人获奖记录与重复获奖统计，而非在程序里填入“1次”。多个年份的比较保留各年度记录，不擅自只选一个年份。

首次范围策略的失败也保留：看到错误的引号姓名就排除名单，会丢掉用于纠正前提的年度公告；仅排除新资料的科学史标签，也挡不住旧库无标签的相对论片段。后续`AwardScopedRetrieverV2`允许同年度、同类别的公告反驳题设姓名；有适用奖项记录时，优先使用该记录而不混入一般科学史。

`nobel_scope_followup_v1`为仍混入旧科学史的原型，`nobel_scope_followup_v2`为测试修复后的19条运行，两者均保存。后续修改来自已经看到的失败，是探索性迭代，不当作新的独立验证。

## 必须保留的失败

- 第27题提供了福瑟获奖公告，模型仍把公告中的挪威作家身份移给“李华”；资料正确不等于主体绑定正确。
- 第29、48题无充分人物获奖证据，模型仍为题设姓名编造获奖领域。未检索到不能证明该姓名的人不存在，也不能验证其获奖身份。
- NP1最终只召回爱因斯坦奖项片段，模型终于提到光电效应，但仍把“1922年颁发”说成“1922年的物理学奖年度”，不能判为完全正确。
- NP3询问1922年度时，过滤器不再借用1921年度记录，但模型在无资料时仍说爱因斯坦。减少错证据并未自动教会模型处理知识缺口。
- 第74题（2020物理学奖）和NP5（2024化学奖）不在补充语料覆盖中，仍有无证据编造；不把部分补库宣传成全奖项覆盖。
- 第76题即使召回爱因斯坦相对论发展史，仍顺从牛顿前提；第84题的瓦特、第99题的太阳矛盾仍在。扩大正确资料仍不足以解决这些生成错误。

北京、声音传播、未知产品参数三个对照继续保留。少量对照不能证明没有正常任务副作用。元数据筛选使用词项和年份规则，不是完整实体消歧、语义支持验证或事实核查器。
