## 知识更新后结果如何复现

旧结果使用旧题集、旧语料、旧源码、旧模型文件哈希和生成配置重放。新知识不覆盖旧corpus或旧run；另建资料版本，分别记录发表日、更新日和采集日，重建索引、新建配置与运行目录后再跑相关对照。题目的截至日期或参考变化也另存数据版本，不把新知识套在旧输出上冒称同一次实验。跨硬件或依赖版本不保证逐token相同；模型不可用时，明确标为历史回放。

## 建议讲述顺序

开场约30秒：我的分工是幻觉数据、可溯源知识库、检索与回答约束，以及这些方法的开发对照。重点是把事实依据、模型输出和评价判断分开保存，使后续联合治理与独立评分可以复现。

数据约45秒：保留原始125题，另建开发副本。核验发现10题参考或题意有问题，17题仍待充分核验；19题提出修订，但修订提案不代表证据已经完整。22条身份或实体不确定的题移除事实真值，避免把没有找到资料误判为不存在。候选参考仍需要第二人确认。

方法约45秒：知识库来自16个可追溯来源、25个片段，检索使用中文二元片段和BM25，按主题过滤后取前两条。核验题目答案使用的来源登记表不自动加入检索库。原四组比较基线、只加约束、只加资料和两者结合，数学题绕过资料检索。知识库与开发题有主题重叠，当前是开发实验。

实验约60秒：87题四组348条、正常任务20题四组80条均实际生成。随后20道开发题加20条正常任务做三策略比较，120条输出中115条来自模型、5条来自程序拒答。前三轮合计548条输出。时延、长度和截断可从日志复核，事实正确率要等待独立评分。AI开发复核只有一位来源，84条记录不能算两人标注。

结论与演示约60秒：约束与资料能改善部分回答，也可能错用证据、产生内部矛盾或只给来源不回答。保守门控避免部分无依据陈述，但会拒答知识库未覆盖的可回答问题。新提示在六道正常任务输出约束上从2/6降到0/6，所以保留候选，不更换默认方案。打开[现场记录](runs/demo_v1/transcript.md)展示真空传声题的正确回答与矛盾回答，再展示程序拒答的明确标记。

收尾约20秒：现已交付可复现输入与源码快照、可恢复运行、独立复核材料和问答接口。两位标注者各192条空白项已经准备好，目前真实人工复核为0。下一阶段是独立评分、分歧裁决、正式数据冻结，再与A的偏见治理组合。

## 常见追问

| 问题 | 可据现有证据回答 |
| --- | --- |
| 幻觉降低了多少？ | 目前没有独立人工统计支持总体降低幅度。可报告运行统计和指定案例，不能把更短、更快或更多拒答当作正确率。 |
| 检索成功就说明回答可信吗？ | 资料命中只说明召回了主题片段，主体归因与实际陈述仍可能不受支持；真空传声演示中命中后仍出现同段矛盾。 |
| 28/28是否说明检索已经充分验证？ | 这是开发者按当前语料编写的诊断，另有2条负例；它检验预期片段召回，不是独立检索基准，也不等于答案正确。 |
| 把参考答案放入知识库了吗？ | 构建程序限制输入字段，语料使用公开来源正文，来源台账与参考答案不自动导入。开发主题重叠仍存在，需要冻结后的独立评价。 |
| 产品查不到为什么不判虚构？ | 未检索到资料无法证明实体不存在，题目作为不确定性探针，核心真值不计入正确率分母。 |
| 程序拒答算模型能力吗？ | 不算。answer_origin=policy_abstention且model_calls=0，单独统计。 |
| 为什么不用新策略替换旧策略？ | 改善与退化并存，正常任务输出约束退化，门控还会错拒常识题；当前证据不足以支持整体替换。 |
| 38道未参与上一轮的题算独立测试吗？ | 尚未正式冻结或完成近似题检查，不能自动当作独立测试。现场演示也不是新增测试集。 |
| C是否完成了整个联合治理？ | 当前交付C的接口与开发消融；项目E1偏见治理和E3联合治理仍需A接入与共同验证。 |
