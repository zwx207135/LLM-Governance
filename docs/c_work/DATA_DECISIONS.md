## 保留的确定身份核对

第27、30、31题的问题限定了具体年度和奖项，已查到相应完整获奖名单，因此可以核对题设获奖身份是否符合。候选参考删去了同名人物不存在的断言。这三题与其余实体题区别在于有可检验的封闭身份范围，仍需第二人复核。

## 修订与划分

修订建议逐字段保存在data_change_proposals.json，不直接改写原题集。第63题明确金牌并列与奖牌表排序，第111题区分平方根与算术平方根，第107和117题明确数列规则，现任职务题固定截至日期。

data_usage.json保存全部ID的数据用途与已知关联组。本轮87题用于开发，38题未参与本轮生成；这不是独立盲测承诺。正式测试应由B确认分组和近似重复，由C、D确认参考与评分规则。若无法给开放世界实体题建立可接受的证据范围，应保持为不确定性行为探针，或另行设计给定材料的封闭任务。
