# 材料任务的不同失败类型

下面是开发者阅读本轮原件的说明，不计作新增独立人工评分。全部原始回答与自动规则保留在[中文报告](runs/balanced_labels_cn_v1/report.md)及其cases目录，自动符合数仍按冻结的字段要求计算。

## 结论正确，依据引用了无关材料

P01a的目标陈述为太阳系只有一颗恒星，M1是小米YU7资料，M2是太阳资料。compact普通生成判支持，却把basis写为M1并引用YU7内容；compact约束生成也选了M1。这里同时存在实际资料错配，不能因为结论碰巧正确就视为有证据支持。

## 标签正确，附加说明与材料矛盾

P11a的目标陈述把电灯全部贡献归给爱迪生一人。材料明确记载多人贡献、爱迪生团队和斯旺。compact普通生成判反驳，却在basis中说材料未提及爱迪生在电灯发展中的贡献。标签与附加说明须分别审阅，单看标签会遗漏错误说明。

## 资料相关，但没有遵守限定字段值

P10b的陈述核对陈晓东记录中的材料学院任职。legacy普通生成判支持，basis写为M1后附完整任职文字，该材料确实相关。由于题目要求basis只能是M1、M2、none，规则把它记为字段不符合；不能仅据这个机器结果将整段判断称为虚假事实。原始文字保留供真人分开评价有用性、格式与事实性。

## 格式合格，结论与依据字段仍不协调

P12a问给定材料能否确认SU9的加速。compact约束生成判不足，却选择M1作依据，未选none。有限schema容许所有9种组合，没有读取正确答案或把不足自动修成none，所以能显露出模型自己的字段选择问题。格式约束本身不保证结论与证据关系一致。

## 如何使用这些案例

评估应同时保留结论、实际依据和完整输出。错误编号有时是无关资料错引，有时是规范外的附加正文；需要真人按材料核对，不能统一当作幻觉或统一当作小格式问题。素材位置变体、两种标签措辞及重复提示都来自相关主题，不能作为大量独立能力证据。
