# C：主体错配单轮开发对照

本轮将计划中的主体绑定研究限定为一次冻结实验：相同问题、相同资料，比较原combined与`SubjectFocusPolicy`。只对引号内容未匹配年度获奖记录主体的案例，在提示末尾追加两步任务：先读资料中的获奖者，再说明题设姓名的身份是否有证据。它不填入参考答案、不改写原问题、不返回程序答案；字面不匹配也不证明人物不存在。

## 实际运行

17题两组共34次真实模型调用，包含7条已有案例、6条开发探针、4条正常任务。使用相同v4、年份别名检索器、Qwen2.5-0.5B-Instruct、seed和160新token上限，贪心解码。5对实际应用了问题分解、5对回答改变；全部17对资料相同。四对正常任务提示和回答逐字相同。34条中有1条截断，原件保留。

[机器汇总](subject_focus_summary.json)、[完整逐题成对结果](subject_focus_comparison.json)。报告在独立进程导入各轮源码快照，逐条重建问题、实际提示及检索资料；没有用当前修改代码冒充历史版本。

## 这项任务的完成结论

已完成一次有明确范围、同资料对照、完整记录与失败解释的开发检验。结论是该候选不具备稳定收益，作为实验保留。进一步追求主体绑定效果属于后续方法研究，不能把无限尝试新提示列为当前交付必须实现的确定收益。
