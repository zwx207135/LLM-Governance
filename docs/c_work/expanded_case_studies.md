# 扩大开发实验案例

这些案例来自expanded_v3的原始回答，由开发者对照资料检查，尚未经过第二人独立评分。它们用于解释故障与变化，不用于估计总体改善率。完整四组回答、证据与日志均保留。

## 减少错误补充的三个例子

第3题的baseline正确回答太平洋后，又给出109380000平方千米等不一致数据；combined只回答太平洋。召回的ocean-01来自[NOAA海洋资料](https://oceanservice.noaa.gov/facts/biggestocean.html)。这个例子支持检查“核心答案正确但附加事实错误”，不能仅凭答案含有太平洋就判无幻觉。

第16题的baseline说阿姆斯特朗与迈克尔·乔丹一起登月；combined只回答阿姆斯特朗。apollo-crew对照[NASA阿波罗11号任务](https://www.nasa.gov/mission/apollo-11/)记录了阿姆斯特朗、奥尔德林与柯林斯的不同职责，能够发现原始回答的错误人名与任务描述。

第18题的baseline先说声音能在真空传播，又说不能，随后还编造特殊情况；combined回答声音需要物质介质、不能在真空传播。waves-mechanical来自[NASA机械波与电磁波介绍](https://science.nasa.gov/ems/02_anatomy/)。此处不仅检查答案词，还检查完整回答是否自相矛盾。

## 有资料但没有正确使用

第17题combined把挑战者深渊称为世界最深的海沟。trench-depth实际说它是马里亚纳海沟中的最深处；回答混淆海沟与其内部深渊。这说明相关片段已经召回，仍可能出现实体层级错误。

第76题retrieval与combined均召回relativity-special及relativity-general，前者明确爱因斯坦与1905狭义相对论，生成回答仍把牛顿称为广义相对论创始人。该例属于生成未遵循证据，而不是知识库完全没有相关资料。

第99题combined先说太阳是太阳系唯一恒星，随后又说太阳系还有其他恒星，并继续列出行星。资料sun-01已说明唯一恒星，但回答仍有内部矛盾和分类错误。检索命中与语言流畅都不能替代完整回答核验。

第94题combined只输出美国能源部来源名称与链接，没有回答问题。链接真实与任务完成是两回事；应分别评价引用支持、答案有效性与错误前提纠正。

## 不确定性探针与泛化风险

第28题的RAG召回一般相对论资料，却没有关于题设人物的身份证据。combined仍把相对论贡献迁移到王明远身上，最后才说缺少直接资料。这是“主题相关”与“主体证据充分”的差别，不需要断言该姓名人物不存在就能指出当前证据不足。

第32题combined在无资料时说明无法提供具体产品参数；constraint却给出频段、带宽与传输距离等未经支持的数据。该题属于不确定性探针，不能拿原参考中的公司不存在作为评分真值，也不能因一句无法提供就忽略后续是否继续编造。

第38题已改为特斯拉2025年报范围的候选问题，但年报没有进入本轮主题知识库。多个模式仍编造该报告提到Model Z或给出参数。该例说明对题目来源做核验，不代表模型在生成时已获得那份资料；来源登记与RAG入库必须分开记录。

## 结果解释

本轮combined输出较短、截断较少，但以上失败仍存在。没有独立评分前，不能把更短、更快或更少截断解释成幻觉率下降。后续应分别补知识覆盖、改善主体身份匹配与证据遵循，并继续用正常任务观察副作用。0.5B模型上的单次开发案例不能外推到其他模型。
