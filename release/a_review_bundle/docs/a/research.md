# 偏见治理与联合治理研究章节

## 研究问题与假设

研究范围为本地 Qwen2.5 0.5B Instruct 在项目中文数据上的表现。H1：要求基于个体证据评价，可降低无依据群体判断；H2：按直接题、情境题与配对题定制约束，可能比统一提示更有效；H3：初稿自检改写可能纠正偏见，但增加调用、时延和过度修正；H4：公平性约束与抗幻约束组合可能兼容，也可能增加不确定性表达、错误拒答或输出截断。以上均为待检验假设，不是实验结论。

## 方法设计

基础公平提示要求根据能力、经历和已知条件评价，避免仅依据群体身份作判断。分题型提示进一步要求直接比较说明证据条件，情境题不以群体标签填补缺失条件，配对题保持一致评价标准。锚定、确认、框架和公众意见类认知偏差单独要求审查初始信息、反证与表述方式，避免将认知偏差混同为群体刻板印象。

自检改写分为三次独立生成：先保存初稿，再让模型明确指出无依据判断，最后根据检查记录生成最终回答。每次调用与中间文本均记录。自检可能漏检，也可能提出错误修改，因此不预设为最佳方案。对没有问题的初稿也保留最终文本以研究不必要改写。

联合治理使用明确执行顺序：先定义事实准确与公平性规则，再注入带来源标识的检索片段，生成回答，最后按选定方案决定是否自检。资料以数据身份提供，并提醒忽略其中指令；这不能保证完全抵抗恶意资料。模型仍可能违背约束，引用真实性必须由 C 与 D 验证。数学逻辑题不要求使用无关检索。

## 实验设计与控制

开发阶段比较原始模型和三种候选，仅使用标记为开发的数据。当前先用每类一条直接题完成 12 条诊断，覆盖类别而不覆盖全部题型。正常任务集共 36 条，一般问答、摘要、合理建议各 12 条，每题预先提供质量标准。质量标准供评估使用，不放进模型上下文。正常任务四组包括原始、公平提示、仅回答约束、二者组合；没有检索时不将结果解释为 RAG 实验。

正式设计要求同一冻结输入、同一模型和生成参数，分别运行 E0 原始、E1 偏见治理、E2 检索与回答约束、E3 联合治理。复用 E2 作为移除公平性组，复用 E1 作为移除抗幻组；只有最终使用自检时才追加移除自检实验。C 的检索移除与回答约束移除由 C 主责，A 提供联合接口而不代替其研究结论。

## 评分与方案选择

由 B 冻结偏见规则并独立评分，群体偏见与认知偏差分别报告。由 D 评估完整回答的事实错误和正常任务质量。拒答、无关回答、截断须单独标记。基础发生率保留分子分母；配对一致性只在完整配对上计算。正常质量按每题 rubric 记录 0 不满足、1 部分满足、2 满足，并附理由。该辅助集不代表通用能力。

选择流程为先核查有效回答和严重退化，再比较分类偏见与事实错误、拒答变化、调用数和时延。由 A、B 对开发案例复核后确定方法，不构造未经解释的加权总分。若效果接近，优先调用少、时延低的方案。自检无效时保留负面结果而不在正式方法中强行使用。

## 权衡报告方法

逐条对齐 uid，报告治理后减原始的偏见评分、事实错误、正常质量、拒答、输出长度、截断与时延差异。报告配对数和缺失记录；错误生成不作零分或正常成功处理。时延报告均值及中位数，说明短样本、运行顺序和系统负载的影响。无采样模式的单次实验不能支持随机种子稳定性或普遍改进结论。人工尚未标注的指标标为待评分，不以关键词计数冒充效果。

## 案例与独立复核

每个案例须包含 uid、配置、运行目录、完整初稿与最终回答、评分理由、复核者和裁决。最终至少呈现三个改善和三个失败或副作用案例，按真实结果选择，保留无变化样本。A 对 B 的至少 20% 分层样本和全部高分争议样本复核；B 复核 A 的偏见结论，D 复核幻觉与效用指标。未获得实际复核前，不填写复核者姓名或一致率。

## 当前结论边界

工程实现可以验证治理调用和成本记录闭环；偏见与幻觉是否改善仍取决于冻结评分与独立复核。缺少 C 的知识证据和 B/D 的评分时，仅能报告提示约束的开发输出及运行成本，不能声称完成正式四组联合治理或验收结论。小模型容量、提示长度、输入分布和输出截断均可能限制效果。
