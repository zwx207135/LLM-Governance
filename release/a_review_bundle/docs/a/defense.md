# A 同学答辩内容与讲稿

以下为交给 D 组装的四页内容。效果数值须来自独立评分后的正式实验；成本诊断见实测报告。

## 第 1 页 研究问题与三种方案

页面内容：个体证据公平提示；分题型提示；初稿—检查—改写。研究问题是能否减少无依据判断，以及是否增加错误拒答与成本。

讲稿：我负责偏见治理方法和联合治理。基础方案要求模型按照个体证据作答，分题型方案进一步限制比较和情境评价的标准，自检方案保留初稿、检查和最终改写。我们没有把自检预设为最优，而是让开发集表现与成本共同决定。

## 第 2 页 联合执行顺序

页面内容：事实约束与公平性规则 → 带来源证据 → 初稿 → 可选自检改写。区分真实检索联合组和仅回答约束诊断组。

讲稿：C 提供经过核验的检索资料，我负责将证据使用和公平性要求接到同一生成链路。每条回答保存使用的证据与调用记录。没有实际检索资料时，只能称为回答约束试验，不能作为完整联合治理成果。

## 第 3 页 对照与消融

页面内容：E0、E1、E2、E3 同输入同参数；移除公平性复用 E2，移除抗幻复用 E1；采用自检才追加自检消融。开发测试隔离，按 uid 成对比较。

讲稿：我们通过四组实验分清各组件作用。对照不只看一个汇总分，还要看类别差异、正常任务质量、拒答、长度与耗时。正式方法在开发阶段确定，测试集不参与选提示词。

## 第 4 页 效用代价与局限

页面内容：36 条正常任务；偏见、事实错误、质量和拒答分别报告；三个改善与三个失败案例待独立评分选择；小模型与单次实验结论限于当前范围。

讲稿：治理可能减少无依据判断，同时也可能使回答更长、更慢或过度保守。我们保留负面结果，并由其他同学独立复核。当前工程闭环和成本记录已经有了可复现实验入口，正式效果结论需要完整评分和证据链。

## 问答准备

- 为什么不强制自检？自检多两次调用，而且模型可能误判初稿，要由开发实验决定。
- 为什么不能全部拒答？正常任务仍须有用，拒答变化和错误拒答单独报告。
- 抗幻提示是否等于 RAG？不是。RAG 必须真实检索并记录独立来源、快照和命中情况。
- 如何防止测试泄漏？只在开发集选择方法，跨集重复和配对同组，由 B 冻结；参考答案不注入提示或知识库。
- 如果指标没有提升怎么办？报告分类退化、无变化、成本和失败原因，不删负面结果。
- A 是否能独自确认治理有效？不能；B 独立复核偏见，D 复核事实与效用，C 复核证据使用。
